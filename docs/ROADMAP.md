# 后续任务与验收标准

现有版本已具备麦克风录音、分段本地转录预览、录音结束后的最终转录与笔记任务、文档编辑导出及 macOS 桌面打包。后续按以下顺序推进；未勾选的验收不能用模拟测试代替。

## P0：扩大试用前完成

- [ ] **另一台 Mac 的下载安装验收**：通过 GitHub Release 的真实下载链接，在符合系统要求的 M 系列 Mac 安装；检查首次打开、模型下载、麦克风权限、导入导出、重开后的数据和退出清理。记录芯片与系统版本；不能只复制本机构建目录验证。
- [ ] **真实课堂录音完整流程**：先测试 10—20 分钟，再测试 45—60 分钟；覆盖开始、暂停、继续、实时预览、结束录音、最终转录和自动笔记。记录漏音、术语错误、时间戳偏差、识别延迟、总耗时和峰值内存，并抽查引用是否对应原文。
- [ ] **真实 AI API／中转服务联调**：由使用者在本机配置自己的 URL、模型和密钥，确认发送范围后测试主题归并、口语碎片整理、来源引用、分块、超时、错误输出与手动重试。至少完成一个实际服务的端到端验收；现有模拟接口测试不代表真实兼容性或笔记质量通过。

## P1：首次使用与录音可靠性

- [ ] **模型管理入口**：在界面提供模型准备、下载进度、失败重试和就绪状态，让用户能在录音前准备 small；目前设置页只显示状态，模型在最终转录任务中下载。
- [ ] **录音持久化与恢复**：增量保存未提交的录音片段；刷新或异常退出后提供恢复入口。验证存储不足、麦克风断开、休眠／唤醒、权限拒绝和识别积压时的音频保留。当前未保存录音不能在刷新或崩溃后恢复。

## P2：维护与迁移

- [ ] **备份恢复与换机迁移**：现有 JSON 导出之外补充恢复入口，验证音频、转录版本、笔记修订和引用关联的一致性；明确备份中是否包含接口密钥。
- [ ] **兼容性范围**：验证更多系统版本；如需降低 macOS 26.2 门槛，先评估兼容的 MLX 依赖并重新验证完整安装产物，不能只修改最低版本字段。
- [ ] **发布流程**：逐步自动化打包、隐私审计、SHA256 和 Release 附件核验；完成 P0 后再评估将已验收的 develop 版本合并到 main。

每完成一个经过验证的小功能或修复，独立提交并推送 develop；保持发布标签与对应安装包的源码提交一致。真实课堂材料、接口密钥及个人数据不进入 GitHub。
