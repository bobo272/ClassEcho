# ClassEcho

中文课堂 AI 笔记工具：把课程录音整理成能回听核对、能编辑导出的课程笔记。

> 当前处于项目规划阶段，尚未实现应用功能，也未完成本机转录与模型质量评测。

## 计划中的工作流程

1. 导入课程音视频，在 Apple Silicon Mac 上完成本地转录。
2. 核对转录文字与专业术语，再将所需文本交给云端模型整理。
3. 为笔记关联原始转录片段与时间戳，便于回听核对。
4. 编辑笔记，导出 Markdown、SRT 与 JSON。

原始音视频默认留在本机；云端笔记整理需要发送相关转录文本，因此整个流程并非完全离线。

## 规划技术栈

- 前端：React、TypeScript、Vite
- 后端：Python、FastAPI、Pydantic
- 本地转录与音视频处理：MLX Whisper、FFmpeg
- 数据与后台任务：SQLite、SQLAlchemy、RQ、Redis
- 云端笔记：Qwen-Plus 文本模型

首个目标平台为 Apple Silicon macOS。具体依赖版本、最低系统要求与性能数据将在实际验证后记录。

## 下一步

先用经过许可的 10—20 分钟中文课程材料验证本地转录质量、时间戳、耗时与内存，再完成带片段引用的笔记原型。

当前尚无可运行版本，安装说明、示例与测试结果将在开发过程中补充。
